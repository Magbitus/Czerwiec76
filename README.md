# Gra Miejska: Płock - Trasa Historyczna 🗺️

Interaktywna webowa gra miejska przygotowana dla Płocka. Projekt oparty o czysty HTML, CSS, JavaScript oraz bibliotekę Leaflet.js i otwarte kafelki mapy.

## 🚀 Funkcje
- Kolumnowy interfejs inspirowany nowoczesnymi przewodnikami turystycznymi.
- Interaktywna mapa Płocka z zaznaczonymi punktami historycznymi.
- Synchronizacja listy zadań z markerami na mapie w czasie rzeczywistym.
- Panel szczegółów dla każdego punktu z opisem i zadaniem do wykonania.

## 🛠️ Technologie
- HTML5 / CSS3
- JavaScript (Vanilla JS)
- Leaflet.js (obsługa map)
- OpenStreetMap France (darmowe kafle map w standardzie Open Source)

## ⚙️ Jak uruchomić lokalnie
1. Sklonuj lub pobierz repozytorium na swój komputer.
2. Otwórz folder projektu w edytorze **Visual Studio Code**.
3. Upewnij się, że masz zainstalowane rozszerzenie **Live Server**.
4. Otwórz plik `index.html` i kliknij **"Go Live"** w prawym dolnym rogu edytora.
